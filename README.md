# Library Nebari

A Vercel-ready Next.js website containing public-domain books and short personal reviews.

## Run on your Mac

1. Unzip this folder.
2. Open Terminal and enter the folder with `cd`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Publish

Create a new GitHub repository named `library-nebari`, push this folder to it, then import that repository into Vercel. After deployment, add `library.nebari.com.au` in the Vercel project's Domains settings.

Books and reviews are stored in the `books` list near the top of `app/page.tsx`.
